English speech clarity diagnosis — corrected training run

Scope: local CPU inference only. No changes to active training, feature arrays,
checkpoints, cloud resources or spending safeguards. No direct human listening
performed by the assistant. User reports unclear English speech. ASR success
on a short preview is not proof of natural or clear speech.

Confirmed checks
- No clipping, non-finite audio, dropped input phones or zero-duration phones
  in the tested previews. Checkpoint weights are loaded strictly and matched
  to SHA256 metadata. Both synthesis and vocoder use 22,050 Hz, 80 mel bins,
  FFT/window 1,024, hop 256, mel frequency range 0–8,000 Hz. Model uses eval mode.
- Best step 12,000 produces the six-word preview in 1.405 seconds (~256 words
  per minute). A separate diagnostic duration-control=1.3 version lasts 1.695
  seconds. Both are transcribed exactly by unprompted local Whisper-small.
  This control changes predicted phoneme durations before vocoding; it does
  not time-stretch finished audio. It is a listening candidate, not a proven
  quality fix. Original preview files are preserved.
- English training contains 3,037 clips across 254 estimated speaker clusters,
  median seven clips per cluster. Preview cluster en_est_0155 contains 89 clips
  and 6.932 minutes of aligned training audio. Cluster identity accuracy has
  not been verified. Data scarcity and uncertain labels are plausible causes
  of weak voice/acoustic generalization, not experimentally isolated causes.

Best-model supplied true durations: 3.309 seconds, mel MAE 0.92515.
Best-model supplied true duration/pitch/energy: 3.309 seconds, mel MAE 0.89962.
The acoustic output remains visibly smoother than the true mel even with all
variance targets supplied. This points to a remaining acoustic-model limitation,
not a problem confined to predicted timing. MAE is not a perceptual score.
Supplying reference controls did not consistently reduce transcription errors.

The newer locally verified checkpoint is also tested; its actual step/hash is
in diagnosis.json. Both newer and best previews transcribe exactly; both free
held-out outputs omit WIC. No measured transcription gain on these two texts.
The training/validation logs show much lower training error than validation
error and a validation plateau. More identical updates are not guaranteed to
resolve voice clarity. This is not proof of convergence or a robust WER study.

Vocoder controls
The earlier corrected-feature vocoder test reconstructs natural English text
exactly and matches saved/fresh mel analysis to ~1.9e-6 MAE. The new same-cluster
control also largely preserves the text. Thus a gross vocoder format mismatch
is not supported by these controls. Vocoder perceptual artifacts remain possible.

Recommendation
Use the best checkpoint as the baseline; audition the slower diagnostic before
changing inference defaults. Review several natural recordings within the
chosen estimated cluster and compare multiple speakers/held-out sentences.
If clarity remains inadequate, prioritize speaker/data consistency and acoustic
generalization before spending on an extended unchanged training run. No new
training, label change or model selection is authorized by this diagnosis alone.
